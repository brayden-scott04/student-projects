# OOP Assignments

This folder contains three assignments completed as part of an Object-Oriented Programming (OOP) module, written in Python.

## Assignments

| Folder | Topic | Key Concepts |
|--------|-------|--------------|
| Assignment1 | Personal Training Management System | Classes, encapsulation, private attributes |
| Assignment2 | Clinic Booking System | Abstract classes, inheritance, polymorphism |
| Assignment3 | Movie Analytics System | File I/O, CSV parsing, data filtering |
